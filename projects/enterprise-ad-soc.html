ENTERPRISE INFRASTRUCTURE • SOC • CYBERSECURITY

Enterprise Active Directory & SOC Environment

A segmented enterprise-style Windows infrastructure integrating Active Directory, pfSense, Splunk, Sysmon and Snort.

This project was built to develop practical experience in systems administration, networking, cybersecurity, security monitoring, detection engineering and enterprise troubleshooting.

Explore Project Watch Demo

Project Overview

I designed and built an enterprise-style infrastructure in VMware Workstation using multiple Windows Server systems, segmented networks, centralized identity management, firewall controls and centralized security monitoring.

The environment evolved from an Active Directory lab into a broader security operations environment incorporating network segmentation, endpoint telemetry, intrusion detection and SIEM-based monitoring.

Architecture

Network Segmentation

Servers / LAN — 172.16.10.0/24

Clients — 172.16.20.0/24

Management — 172.16.30.0/24

DMZ — 172.16.40.0/24

External / Security Testing — 172.16.50.0/24

Core Systems

DC01 — Active Directory / DNS

DC02 — Secondary Domain Controller / DNS

SPLUNK01 — Splunk Enterprise SIEM

ClientMachine — Domain-joined Windows endpoint

pfSense — Routing / Firewall / DHCP

Kali Linux — Controlled security-testing system

Technologies Used

Windows Server 2022 Active Directory Group Policy DNS VMware Workstation pfSense Splunk Enterprise Sysmon Snort IDS PowerShell Kali Linux

Active Directory

I deployed the corp.local Active Directory domain using two domain controllers to provide centralized authentication, DNS, Group Policy and directory services.

Organizational Units, users, security groups and policies were created to simulate centralized administration in an enterprise Windows environment.

Network Security & Segmentation

pfSense operates as the central routing and firewall platform between the different network segments.

Separate VMware networks were created for servers, clients, management systems, DMZ systems and controlled external security testing. Firewall policies control communication between these networks.

Security Monitoring

Splunk Enterprise was deployed as the centralized SIEM platform. Windows Event Logs and Sysmon telemetry were collected from Windows systems while pfSense and Snort supplied network-security visibility.

SOC dashboards and searches were developed for authentication events, account activity, PowerShell execution, privileged-group changes, firewall events and IDS detections.

Detection Engineering

I created detection searches for failed authentication, account lockouts, account changes, PowerShell activity, privileged-group modifications, Kerberos and NTLM failures, discovery activity and other security-relevant behavior.

I also worked with authentication correlation to identify patterns involving multiple failed authentication attempts followed by a successful authentication.

Troubleshooting & Lessons Learned

A significant part of the project involved diagnosing real configuration problems rather than simply following installation procedures.

Troubleshooting included inter-network connectivity, Windows Firewall, pfSense firewall policy, VMware virtual network mappings, DNS, Splunk log ingestion, Snort field extraction and VM resource constraints.

These problems reinforced the importance of validating each layer independently instead of assuming that a configuration is working.

Results

The completed environment provides centralized identity management, segmented networking, firewall enforcement, endpoint telemetry, intrusion detection and centralized SIEM visibility.

The project provides a platform for additional work in EDR, security automation, incident response, cloud integration and advanced detection engineering.
