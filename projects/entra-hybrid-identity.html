Microsoft Entra ID Hybrid Identity

Extending an on-premises Active Directory environment into Microsoft Entra ID.

Project Overview

This project extends the existing corp.local Active Directory infrastructure into Microsoft Entra ID to create a hybrid identity environment.

The implementation includes public-domain verification, Active Directory UPN configuration, Microsoft Entra Connect, identity synchronization and hybrid authentication testing.
